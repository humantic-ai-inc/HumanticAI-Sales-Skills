# Sales Prompts

Fifty-five prompts for sellers using Humantic AI through an AI assistant. Each one is a single request you paste and send.

[Back to the repo home](../README.md)

**Prompts or skills?** A prompt is one request. A skill is a full workflow the assistant runs for you, and it uses several of these prompts inside it. If you want meeting prep, a buyer read, prospecting or email done end to end, [install the skills](../INSTALL.md). Use these prompts when you want one quick answer.

**How to copy one.** Each prompt sits in a grey box. Hover over the box and a copy button appears in its top-right corner. Paste it into your assistant, then replace anything in [square brackets] with the real name or company. The line breaks in the box do not matter.

**First time?** Connect Humantic AI to your assistant with [the setup guide](../docs/setup-humantic.md).

## How to use these

**One identifier per person.** Give a LinkedIn URL *or* an email, never both in the same request. There is no linking step, so if you want both to work later, ask for each separately.

**Ask for the format you want.** If you want something you can share or print, say so in the prompt rather than relying on the default.

**Your other tools make these better, and none of them are required.** If your assistant can see your calendar, mail, CRM, meeting notes or files, these prompts use them. If it cannot, it asks you for what would help. If you would rather not share anything, you still get the best read Humantic alone can give. See [the connectors page](../docs/connectors.md) for what each connector adds and where.

## Two things to know before you rely on this

**A personality read is a guide, not a verdict.** It tells you how to approach someone. It does not tell you whether a deal will close, and it belongs alongside what you already know rather than in place of it. This matters most in the buying-committee prompts, where the value is in spotting a pattern worth checking rather than in treating the read as settled.

**Section 09 needs at least one other tool connected.** Those prompts combine Humantic with your calendar, mail, CRM or files, so they depend on what your assistant can reach. Everything in sections 01 to 08 and 10 works with Humantic alone.
